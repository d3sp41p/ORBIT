# Решения владельца

Журнал решений, которые меняют или уточняют правила игры. Главный документ — `docs/SPEC.md`; здесь фиксируется то, что владелец решил по ходу работы.

| Дата | Решение | Где в коде |
| --- | --- | --- |
| 2026-10-08 | Монеты ещё нет: запуск в лайве, адрес (CA) подставляется в `TOKEN_MINT` в день запуска. До этого индексер работает на стороннем pump.fun-токене как на стенде. | `.env.example`, настройки хостинга |
| 2026-10-08 | Технические счета (bonding curve pump.fun, пулы ликвидности и другие счета программ — адреса вне кривой ed25519) исключаются автоматически. Плюс ручной список `EXCLUDED_WALLETS` (адрес сжигания и т. п.). Мультисиг-кошельки тоже попадут под автоисключение — при необходимости их можно вернуть списком `INCLUDED_WALLETS`. | `packages/core/src/chain.ts` |
| 2026-10-08 | Кошельки команды скрыты: их адреса добавляются в `EXCLUDED_WALLETS`. | настройки хостинга |
| 2026-10-08 | Порог «пыли» `MIN_HOLDING_TOKENS` = 100 000 токенов. | `.env.example`, `packages/core/src/config.ts` |
| 2026-10-08 | Seed симуляции: жизнь 1 — `wallet + "sim"` (как в прототипе), следующие жизни — `wallet + "sim" + life_no`. Повторная покупка после полной продажи — новая планета с нуля (вариант по умолчанию из ТЗ). | `packages/core/src/sim.ts` |
| 2026-10-08 | Перед bloom добавлен проход, заменяющий NaN/Inf-пиксели чёрными (лечит мерцание кадра на части видеокарт). Шейдеры прототипа не менялись. | `apps/web/orbit/sanitize.ts` |
