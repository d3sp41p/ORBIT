# Решения владельца

Журнал решений, которые меняют или уточняют правила игры. Главный документ — `docs/SPEC.md`; здесь фиксируется то, что владелец решил по ходу работы.

| Дата | Решение | Где в коде |
| --- | --- | --- |
| 2026-10-08 | Монеты ещё нет: запуск в лайве, адрес (CA) подставляется в `TOKEN_MINT` в день запуска. До этого индексер работает на стороннем pump.fun-токене как на стенде. | `.env.example`, настройки хостинга |
| 2026-10-08 | Технические счета (bonding curve pump.fun, пулы ликвидности и другие счета программ — адреса вне кривой ed25519) исключаются автоматически. Плюс ручной список `EXCLUDED_WALLETS` (адрес сжигания и т. п.). Мультисиг-кошельки тоже попадут под автоисключение — при необходимости их можно вернуть списком `INCLUDED_WALLETS`. | `packages/core/src/chain.ts` |
| 2026-10-08 | Кошельки команды скрыты: их адреса добавляются в `EXCLUDED_WALLETS`. | настройки хостинга |
| 2026-10-08 | Порог «пыли» `MIN_HOLDING_TOKENS` = 100 000 токенов. | `.env.example`, `packages/core/src/config.ts` |
| 2026-10-08 | Seed симуляции: жизнь 1 — `wallet + "sim"` (как в прототипе), следующие жизни — `wallet + "sim" + life_no`. Повторная покупка после полной продажи — новая планета с нуля (вариант по умолчанию из ТЗ). | `packages/core/src/sim.ts` |
| 2026-10-08 | Перед bloom добавлен проход, заменяющий NaN/Inf-пиксели чёрными (лечит мерцание кадра на части видеокарт). Шейдеры прототипа не менялись. | `apps/web/orbit/sanitize.ts` |
| 2026-10-08 | Автоподвязка монеты при запуске. Адрес монеты, тикер, ссылки и исключённые кошельки хранятся в базе (`token_config`), а не в переменных окружения (отступление от ТЗ ради скорости: переключение без пересборки). `pnpm launch:arm` следит за dev-кошельком и сам переключает систему, когда с него создаётся монета с ожидаемыми тикером и названием; dev-кошелёк при этом автоматически скрывается. Запасной путь — `pnpm launch <CA>`. Отрепетировано на реальной pump.fun-монете: переключение и восстановление истории без расхождений с блокчейном. | `apps/worker/src/controller.ts`, `scripts/launch.mjs` |
| 2026-10-09 | Ранг меняется со временем (в прототипе — нет). Вариант А: **природа планеты фиксируется при рождении** — тип симуляции (каменная / газовая / ледяная / астероид), стартовая температура, климат; **размер, класс по рангу и бонус к стабильности и технологиям следуют за текущим рангом**. Формулы не меняются — на вход тика подаются текущие размер и бонус. | `apps/worker/src/planets.ts` |
| 2026-10-09 | ИИ-тексты (этап 6). Модель Claude Haiku 5.5, рассуждения выключены, дневной лимит `AI_DAILY_BUDGET_USD` = $2.5 (владелец). Запрос отправляется, только если его худшая стоимость влезает в остаток лимита. Уточнения к ТЗ: (1) ИИ переписывает только свежие новости (до 6 часов), старые и догнанные после простоя остаются шаблонными; (2) проверка ответа: до 280 символов, формат «Заголовок: текст», все числа шаблона на месте и никаких других (цифры внутри имён вроде «Solbro 8GI» не считаются), без денег, цен, ссылок и разметки; (3) не прошедший проверку текст пробуется до 3 раз, потом остаётся шаблон; (4) исходный шаблон сохраняется в `planet_events.text_template` для проверок; (5) культура цивилизации хранится в `planet_state.bible.lore` и привязана к виду; (6) летопись заказывается сайтом при открытии страницы через функцию `request_chronicle` (очередь только если летописи нет или она отстала на 5+ событий). | `packages/core/src/ai.ts`, `apps/worker/src/ai.ts`, `supabase/migrations/0011_ai.sql` |
| 2026-10-09 | Кошелёк и настройка (этап 7). (1) Подключение через **Wallet Standard** — тот же протокол, через который Phantom и Solflare подключаются к сайтам, — вместо React-обёртки Wallet Adapter: меньше кода в браузере, те же кошельки; на телефоне без расширения — кнопки «Open in Phantom / Solflare». (2) Подписывается только текстовое сообщение в формате Sign-In With Solana (домен, адрес, nonce на 5 минут); сессия — случайный токен в httpOnly-cookie на 7 дней, в базе хранится только его хеш. (3) В названиях только латиница, цифры, пробел, дефис, апостроф (в девизе ещё знаки препинания): сайт англоязычный, и так закрыты подмены похожими буквами из других алфавитов. (4) Фильтр: библиотека obscenity (английский с обходами) + списки LDNOOBW на 17 языках с латиницей + свой список (русский мат в транслите, оскорбления, «admin»/«official»); короткие слова чужих языков только из ручного списка, чтобы не блокировать «con», «fan», «hard». (5) «Restore defaults» не считается изменением в сутки; новые названия после скрытия админом снова видны (их снова можно обжаловать). (6) При полной продаже названия уходят в архив вместе с планетой (скрытые — нет). | `packages/core/src/moderation.ts`, `packages/core/src/auth.ts`, `apps/web/app/api/auth`, `apps/web/orbit/wallet.ts` |
